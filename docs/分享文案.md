给 Mac 上的 Codex 做了一个 14 秒电影感启动动画：星际穿梭、粒子标志重组、代码流、悬浮工作台，最后切入真正的 Codex。

支持月光银 / 琥珀 / 星云紫，配色自动保存，Esc 随时跳过。启动器独立运行，不修改官方客户端。Codex 没开时会启动它，已经开着就回到现有窗口。
