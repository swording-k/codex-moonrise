# 拍视频：把启动动画和重启入口讲清楚

[快捷指令配置教程](../Shortcuts/README.md) · [项目首页](../README.md)

## 45–60 秒演示顺序

| 镜头 | 建议画面 | 讲解重点 |
| --- | --- | --- |
| 0–5 秒 | 鼠标点击 Dock 或桌面已有快捷指令入口 | “给 Mac 上的 Codex 加一套电影感启动方式。” |
| 5–19 秒 | 完整录下粒子、标志、代码流和悬浮工作台 | 留出完整 14 秒，不把动画中的进度描述成真实模型加载进度。 |
| 19–25 秒 | 动画退出，露出真正的 Codex 客户端 | “动画结束后自动进入真实客户端，不是停在一张模拟界面里。” |
| 25–40 秒 | 展示快捷指令编辑器的三个操作 | “退出真正的客户端，等待 3 秒，再打开 Moonrise。” |
| 40–50 秒 | 展示三种配色和 GitHub 仓库 | “三种颜色、Esc 跳过，源码、下载和教程都在仓库。” |
| 50–60 秒 | 项目链接与原作致谢 | “Mac 版由这个项目实现，参考了 Artemis / Tom 的开源启动器。” |

## 可直接念的口播

> 我给 Mac 上的 Codex 做了一个 14 秒电影感开场：星际穿梭、粒子标志重组、代码流、悬浮工作台，最后进入真正的客户端。
>
> 日常只需要点一个入口。这是系统自带的快捷指令：退出原来的 Codex 或 ChatGPT，等 3 秒，再打开动画启动器 Moonrise。没打开就启动，已经打开就退出重开。
>
> 如果只想播放动画、保留现有窗口，直接点 Moonrise 就行。月光银、琥珀、星云紫都能切换，按 Esc 可以跳过。
>
> 这套方法不改官方客户端。源码、Mac 下载包和三步配置教程都已经开源，链接放在简介里，也感谢原开源项目提供灵感。

## 录制前准备

- 准备一个空白或不含私人内容的工作区，关闭正在执行的任务，再演示真正的退出重启。
- 先录“未运行 → 动画 → 客户端打开”，再录“已运行 → 点击快捷指令 → 退出重开”，清楚展示两种状态。
- 如只拍视觉镜头，可以用 [浏览器预览](https://swording-k.github.io/codex-moonrise/)；说明这是效果预览，不把它剪成已经完成客户端冷启动的证据。
- 将 Dock / 桌面入口名称设置成你喜欢的名字即可；演示时解释背后是快捷指令与独立启动器。
